## Selected projects

### Mail.ai
A natural-language Gmail scheduling assistant. Describe an email and when it should arrive, review the schedule, and send it through your Gmail account.

**Built with:** Spring Boot, AWS Bedrock, PostgreSQL, MongoDB, QStash, Google OAuth, and Gmail API.

[Live app](https://mail-ai-web-beta.vercel.app/) · [Backend](https://github.com/Mangesh1511/gmail-scheduler) · [Frontend](https://github.com/Mangesh1511/mail-ai-web)

### Spring Jetty MCP Server
A lightweight MCP server for traditional Java/Spring applications, with a custom orchestration layer for annotation-based tool discovery and execution through a servlet pipeline.

**Built with:** Java, Spring Framework, Jetty, Maven, and Servlet API.

[Source](https://github.com/Mangesh1511/spring-jetty-mcp-server) · [Architecture walkthrough](https://medium.com/@manpatil1451/how-to-build-an-mcp-server-in-java-with-spring-857eef9ce102)
